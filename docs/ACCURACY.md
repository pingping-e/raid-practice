## 기믹별 구현과 근사

- **절단:** 탱커를 제외한 18명을 9명씩 2개 소킹 조로 나눕니다. 파티 4개 조와 무관합니다. 판정 순간 방향 반각 0.62rad·19yd 내 해당 조 전원과 취약(7초)을 확인합니다. 다른 조 인원이 들어와도 빈자리를 대신 채우지 않습니다. 이 인원·반경·지속시간은 실제 난이도의 확정값이 아닙니다.
- **유린:** 시전 시작 시 탱커 방향을 고정하고 반각 0.48rad·34yd 전방을 판정합니다. 담당 탱커에 6초 취약을 적용하고 다음 시전은 취약 없는 탱커를 우선합니다. 실제 방향 고정 시점·Caustic Claws 중첩 및 피해 공식은 미확인입니다.
- **폭풍:** 6개의 회오리가 속도 7yd/s로 직선 이동하고 원형 벽에서 반사합니다. 23초 존속·반경 1.7yd는 근사입니다. 실제 회오리 궤적을 추출한 결과가 아닙니다.
- **Fury:** 조건 모드에서 실제 최원거리 인원을 선정합니다. 사전 유도 담당 배정은 이동 목표 안내이며 강제 대상 선정과 별개입니다. 집중 모드에서만 나를 강제 선정합니다. 대상 중심 8yd에 14명이 실제로 모이고 Dig In이 끝나야 발동합니다. 시간 경과로 자동 성공하지 않습니다. 발동이 빠르거나 늦으면 맹독 부여·폭발·잔류 바닥 시각도 함께 바뀝니다. 다른 고정 시전 타임라인까지 재배치하지는 않습니다. 18초 지연 경고는 연습용이며 디버프를 해제하지 않습니다.
- **맹독:** 집결 참여자에게 6초 디버프를 부여하고 45도 십자 방출·24초 바닥을 생성합니다. 십자 접촉 시 5초 전염 디버프를 부여하며 최대 2세대로 제한합니다. 십자 길이는 세대당 3yd 감소합니다. 이 규칙·길이 변화는 검증 전 근사입니다. 십자는 순간이 아닌 0.8초 위험으로 표시합니다.
- **낭종:** Surge 대상 3명이 배치합니다. 봇 마커는 다음 강풍의 반대 방향 순서를 참고하고 유저는 설정한 마커를 사용합니다. 1.2초 생성 유예 후 접촉하면 1회 소모, 주변 8yd 반동·4초 감속을 적용합니다. 준비 전 잘못 터뜨려도 재생성하지 않습니다. 실제 발동 반경·감속·생성 유예는 미확인입니다.
- **교차 강풍:** 근사로 비탱커 8명을 선정하고 쌍으로 배정합니다. 유저 대상 시 설정된 짝을 함께 포함합니다. 예고 동안 마주보는 지점으로 이동하고 2초 동안 실제 속도를 부여합니다. 상대 이동 선분의 최소 거리가 2.1yd 이내면 상쇄합니다. 직각 짝 대응, 실제 대상 방향 제약, 무관한 쌍 간 충돌은 미구현입니다.
- **강풍:** 24초 구간에 세 방향(6/13/20초)으로 속도를 가합니다. 담당 순서의 봇은 가까운 낭종에 접근합니다. 낭종 감속이 있으면 바람 속도를 완화하며, 없으면 실패를 기록합니다. 바람의 실제 시간·방향·물리는 검증 전입니다. 봇의 자원 선택은 전 공대 최적 계획이 아니며 낭종이 부족하거나 조기 소모될 수 있습니다.

## 공통 엔진

고정 1/60초 스텝, 시드 PRNG, 같은 고정 스텝 수의 결과는 렌더 프레임·배속에 무관하게 재현됩니다. 무작위 대상은 실전의 실제 대상 정책이 확인된 것이 아니며 Fury만 요구사항의 최원거리 조건을 반영합니다. 봇은 규칙 목표와 이동·위험 회피를 분리했지만 고급 경로 탐색·인간 반응 지연·완벽한 공략 수행은 구현하지 않았습니다.

구간 이동은 초기 시드·배정부터 선택 시각까지 **플레이어도 봇 목표를 따르는 기준 경로로** 재시뮬레이션합니다. 모든 현재 상태와 RNG를 복원하며 과거 결과를 점수에 넣지 않습니다. 이전에 사용자가 실제로 조작한 경로의 녹화 복원이 아닙니다. 동일 시드 재도전도 사용자 이동이 달라지면 실제 대상·결과가 달라집니다.

딜·힐·스킬·일반 공격·피해량·사망·전멸·위협 수치는 모델링하지 않습니다. 피격·경계·협동 실패를 기록하고 끝까지 연습합니다. 점프는 캐릭터에 수직 운동을 주지만 바닥·회오리 판정을 우회하지 않습니다. 전장 경계에서 위치를 제한하고 실패를 기록합니다. 실제 비행·낙사 물리와 같지 않습니다.

현재 기본 스조라크는 기본 전투/강풍 구간 반복 구조입니다. 공통 코어에는 이벤트 스케줄러와 구간 복원이 있으나 별도 보스용 범용 체력 페이즈 전이 API는 아직 없습니다. 다른 보스 데이터 확장 시 구현해야 합니다.
